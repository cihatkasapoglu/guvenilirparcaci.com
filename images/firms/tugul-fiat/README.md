# Tuğul Fiat firma görselleri

Bu klasöre Tuğul Fiat'a ait firma görsellerini yükleyin.

Önerilen dosya adları:
- `tugul-fiat.webp` (firma logosu veya kapak görseli)
- `tugul-fiat-1.webp`
- `tugul-fiat-2.webp`
- `tugul-fiat-3.webp`

Görseller yüklendikten sonra `brands.js` içindeki Tuğul Fiat kaydının `photos` listesine dosya yolları eklenecek. İlk görsel istenirse profil logosu olarak da kullanılabilir.
