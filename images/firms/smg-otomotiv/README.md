# SMG Otomotiv firma görselleri

Bu klasöre SMG Otomotiv'e ait firma görsellerini yükleyin.

Önerilen dosya adları:
- `smg-otomotiv.webp` (firma logosu veya kapak görseli)
- `smg-otomotiv-1.webp`
- `smg-otomotiv-2.webp`
- `smg-otomotiv-3.webp`

Görseller yüklendikten sonra `brands.js` içindeki SMG Otomotiv kaydının `photos` listesine dosya yolları eklenecek. İlk görsel istenirse profil logosu olarak da kullanılabilir.
